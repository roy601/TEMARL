# Devil's Advocate Review — CADO reproduction package

This independent adversarial check is **not a claim that a separate external reviewer audited the project**; it documents our own critical scrutiny, including failures.

## Strong evidence

- The source implementation is the real user-uploaded official supplement, not a reverse-engineered approximation.
- The original ZIP passed CRC/integrity inspection and all 63 entries were enumerated.
- All 1,440 rerun primary episode rows and 360 rerun held-out episode rows matched the archived scientific columns exactly at `atol=1e-12`, `rtol=0`.
- 1,710 ablation-episode rows, 120 fault-injection rows, seed summaries, and ordinary summaries matched; timing-dependent columns were explicitly excluded.
- The author-provided `revision_analysis.py` was independently executed with 26 sensitivity settings. Its default CADO/Consensus episode metrics and held-out paired statistical CSV values match the archived results.
- The five LaTeX table bodies generated by the authors' `export_revision_tables.py` match the archived bodies; their byte representation differs because of Windows CRLF versus Linux LF line endings.
- The local loopback HTTP prototype was independently exercised; it reported 300/300 acceptance criteria, 4,170 requests and 1,770 chained journal entries. This is not a hardware test.

## Known failures or limitations

### 1. Original author's file manifest is incomplete

`publisher_source/SHA256SUMS.txt` contains 57 declarations, but only 56 have matching files. The named `README.md` is **not inside the uploaded ZIP**. The author's `code/verify_manifest.py` fails because this file is missing. We did **not** fabricate a substitute or modify the author's checksum list. A separate `tools/verify_package.py` reports the defect while checking all available files.

### 2. Small statistical p-value drift

With Python 3.13.5, NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0 and matplotlib 3.10.8, the rerun `paired_statistical_comparisons.csv` differs from the author submission for `p_raw` (max absolute error `8.168614368846565e-8`) and `p_holm` (max absolute error `5.71803005819257e-7`) in two comparison rows associated with the unsafe-action metric. The original requirements specify SciPy 1.15.3. The version difference is a plausible explanation, but it is **not proven** without reproducing in the pinned environment. The author's strict `reproduce_submitted.py --verify-only` fails on this discrepancy and the complete reproduced-scientific-values flag is therefore **not** asserted for every statistic. Crucially, Tables 2 and 4 and the held-out paired CSV match.

### 3. Single-command attempt exceeded execution limit

An attempt to run the source script `code/reproduce_submitted.py` through all stages exceeded the command timeout during ablations. The primary, held-out, and fault datasets had already been freshly generated. The ablation, normalization and statistical summary were then independently finished by calling the same original `run_experiments.py` functions, with no parameter changes. `revision_analysis.py`, `export_revision_tables.py`, `verify_claims.py` and `prototype/run_poc.py` were executed thereafter. The execution history is preserved in `evidence/*.log`. Do not describe the author's original one-line full command as having completed successfully here.

### 4. Simulator is synthetic; results do not prove real-world defense

The file `run_experiments.py` explicitly states `SIMULATED_DATA_ONLY=True`. The experiment generates 120-event synthetic episodes across three scenarios, attack profiles and 30 paired seeds. CADO is a constraint-aware policy, not a trained Transformer/GNN/PPO/MARL model. Reproducing this benchmark is not evidence of effectiveness against live adversaries or performance in CybORG/CAGE4 without a fair adaptation.

### 5. Timing must not be compared across hardware

Decision latency, normalizer throughput and other wall-clock measurements depend on hardware, operating system, Python, and library versions; they were excluded from scientific equality checks and retained unaltered in CSVs for transparency.

### 6. The archive's own audit JSON is not our independent audit

`publisher_source/revision_results/full_reproduction_audit.json` is **author-provided** and claims 1e-12 agreement under their environment. It was not relabeled as independent. Our independent audit is `evidence/independent_scientific_comparison.json` and reports the p-value deviation honestly.

### 7. Comparison to TEMARL needs a shared experiment

For a defensible empirical comparison, adapt TEMARL to the **same synthetic events, actions, observation boundary, seed set and scoring definitions** or rerun CADO under TEMARL's simulator. Do not directly juxtapose CADO's reported utility or redirection precision with differently defined TEMARL measures. Do not fit parameters to force published values.

## Result

**Table 2 and the held-out Table 4: independently reproduced to the archived scientific precision.** The package does not claim all host timings, all published p-values, or real-world field validation were exactly reproduced.
