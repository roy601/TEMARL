## Internal-consistency findings (from the paper only)

1. Table 3's averages equal the means of its 10 rows (all six). The spread across trials (sd 0.9-1.5 points) equals the binomial spread of 1,000 episodes (1.1-1.6), so the trials show evaluation noise only.
2. Table 4's "VAR" is the population variance (divide by n): 0.262, 0.268, 0.26 (with n - 1: 0.291, 0.299, 0.289).
3. Fig. 8 shows an API Server in Subnet 4 that Table 2 does not list.
4. Table 2 gives CVE-2018-8174 as obtaining "User" on Host 2 but "System" on Hosts 3 and 4.
5. Sec. 5.5.2 explains the low HiE success by "CVEs deployed on the honeypots tend to have lower EPSS values than most nodes"; in Table 2 the honeypots' highest EPSS (0.9732) is above every real node except the Web Server (0.9737) and equal to the DB Server. Decision 24 gives the explanation that does follow from Table 2 (a tie).
6. The data statement says "No data was used", while Table 2 is data collected with OpenVAS and Nuclei (February 2025); the network itself is not released beyond Fig. 8 and Table 2.
